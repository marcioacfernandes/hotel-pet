# Hotel Pet — Desenvolvimento Web II

## Apresentação do projeto

O Hotel Pet é um projeto de sistema web para gerenciamento de um hotel destinado à hospedagem de animais de estimação.

O projeto representa a visão do gerente, que possui acesso às funcionalidades de gerenciamento de reservas, pets, usuários, configurações e informações do próprio perfil.

## Tecnologias utilizadas

Nesta etapa, o projeto utiliza:

- HTML5 para a estruturação das páginas.
- CSS3 para a apresentação visual, organização dos elementos e estilização da interface.
- Navegação por links HTML entre as diferentes páginas do sistema.

As funcionalidades dinâmicas em JavaScript serão desenvolvidas nas próximas etapas da atividade.

## Como executar

1. Baixe ou clone o repositório do projeto.
2. Abra a pasta `hotel-pet` no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador.
4. Utilize o menu principal para acessar as páginas do sistema.

Não é necessário instalar bibliotecas, frameworks ou configurar banco de dados para testar a navegação desta etapa.

## Principais módulos

| Módulo | Funcionalidades representadas |
|---|---|
| Acesso | Tela inicial de acesso ao sistema |
| Reservas | Listagem, cadastro, visualização, edição e finalização de reservas |
| Pets | Listagem, cadastro, visualização e edição dos animais |
| Usuários | Listagem, cadastro, visualização e edição de usuários |
| Configurações | Informações e configurações do hotel |
| Meu perfil | Visualização e edição das informações do gerente |

## Organização dos arquivos

- `index.html` — página inicial do sistema.
- `pages/` — páginas dos módulos de reservas, pets, usuários, configurações e perfil.
- `css/style.css` — arquivo de estilização visual.
- `imagens/` — recursos visuais utilizados no projeto.
- `js/` — arquivos destinados às funcionalidades em JavaScript.
